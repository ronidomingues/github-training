Um guia de Git que ensina a fazer Pull Request… e registra a presença dos alunos por Pull Request. 🔀

Em 2025 montei, para a liga acadêmica for_code, uma capacitação de Git e GitHub para quem nunca tinha aberto um terminal. Neste mês fiz uma revisão completa, e o material ficou assim:

📘 Um guia de 88 páginas, com passo a passo para Windows, Linux e macOS
🖥️ Slides para duas horas de aula, com as notas do apresentador na segunda tela
🧩 9 exercícios práticos com respostas: do primeiro commit a um site no ar pelo GitHub Pages

O conteúdo vai da conta protegida com 2FA e dos benefícios de estudante (GitHub Pro e Copilot Student) até branches, conflitos resolvidos sem pânico, Pull Requests, GitHub Actions, Git LFS e commits assinados com GPG ou SSH.

Algumas coisas que aprendi revisando um material de um ano atrás:
• informação de plataforma envelhece rápido: planos, versões de actions e telas mudaram. Por isso, desta vez cada passo foi conferido na documentação oficial;
• exercício precisa ser testado: o de merge prometia um conflito que nunca acontecia. Agora ele acontece de verdade;
• automação também tem bug: a lista de presença gravava a hora do build, e não a do Pull Request. Hoje ela usa a data do histórico do Git.

⚙️ Tudo é LaTeX, compilado pelo GitHub Actions e publicado automaticamente no GitHub Pages.

Capacitação de 2 horas para iniciantes, com guia de 88 páginas, slides com notas do apresentador e 9 exercícios práticos com respostas. Edição 2025, revisada em 2026.
